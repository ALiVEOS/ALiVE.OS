ALiVE

Built by Arma community veterans, the Advanced Light Infantry Virtual Environment (ALiVE) is an easy to use modular mission framework for Arma 3. Its editor modules give players and mission makers everything they need to run realistic military operations up to company level, almost anywhere: command, combat support, service support and logistics.

Main Features

* Virtual Profile System: thousands of units operate across the map with little effect on performance, and spawn into the world when players come near.
* AI Commanders: a layered Operational Command reads the battlefield and sends forces after key objectives.
* Terrain indexes for more than 170 terrains, and the Map Indexer for any other.
* Persistence: campaigns are saved on the server itself, with no database to install.
* Player Support: Combat Support, Combat Service Support and C2ISTAR radio menus, Respawn, View Distance and Advanced Markers.
* The War Room (https://www.alivemod.com/warroom/): your group's servers, a live map of running operations, replays and Server Health.

Installation

* Players: subscribe to ALiVE and CBA_A3 on the Steam Workshop and load both in the Arma 3 Launcher. Manual install: -mod=@CBA_A3;@ALiVE
* Dedicated servers: -mod=@CBA_A3;@ALiVE, plus -serverMod=@alive_wr to report to the War Room.
* The latest fixes go out first on the ALiVE Development Version Workshop item: https://steamcommunity.com/sharedfiles/filedetails/?id=2791077612
